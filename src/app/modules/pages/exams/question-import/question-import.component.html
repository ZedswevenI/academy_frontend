Import Instructions

Upload a .docx file with questions in the following format:

  • [Q] - Marks the start of a question
  • (a), (b), (c), (d) - Options for MCQ questions
  • [qtype] - Question type (mcq, subjective, etc.)
  • [DIFFICULTY] - easy, medium, or hard
  • [ans] - Correct answer(s)
  • [Marks] - Marks allocation
  • [soln] - Solution with images
  • Images will be automatically extracted and displayed
